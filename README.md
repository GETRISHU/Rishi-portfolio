## ⚙️ Run Locally

This is a static frontend portfolio, so no Node.js installation or backend server is required to run the basic website.

### 1. Clone the repository

```bash
git clone https://github.com/GETRISHU/Rishi-portfolio.git
```

### 2. Enter the project

```bash
cd Rishi-portfolio
```

### 3. Open the website

You can open `index.html` directly in your browser.

For a better local development experience, use VS Code with the **Live Server** extension.

## 📈 Performance Considerations

The portfolio uses several frontend techniques to improve the browsing experience:

- Responsive layouts
- Optimized image dimensions
- Lazy loading for project images
- Async image decoding
- Embedded assets
- Minimal vanilla JavaScript for interactions
- CSS media queries for responsive breakpoints

For production deployments, images can be further optimized using modern formats such as **WebP** or **AVIF**.
